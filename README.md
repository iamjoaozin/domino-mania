# Domino Mania

Projeto Unity do jogo Domino Mania.

## Como abrir

- Unity: 2022.3.62f3
- Plataforma alvo: Android
- Abra esta pasta pela Unity Hub: `D:\Dominioes_RECUPERADO_BUILD_0306`
- Ao baixar pelo GitHub, use Git LFS para trazer os APKs grandes.

## Builds

Os APKs gerados ficam na pasta `Builds/Android`.

Arquivos grandes de build (`.apk` e `.aab`) estão versionados com Git LFS.
